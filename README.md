# 🏠 House Price Prediction Web App

## 📌 Project Overview
This project is a Machine Learning-based web application that predicts house prices based on user inputs such as location, size, and number of bedrooms.

## 🚀 Features
- Predict house prices instantly
- User-friendly interface
- ML model integration

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas, NumPy

## ⚙️ Setup
git clone https://github.com/Eswar835/house-price-app.git
cd house-price-app
pip install -r requirements.txt
python app.py

## 🧠 How I Built This Project
1. Data preprocessing
2. Model training using Linear Regression
3. Flask backend
4. Frontend integration
